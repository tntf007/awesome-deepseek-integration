# Human Avatar Engine · מנוע שלד אנושי

תשתית פתוחה לדמות אנושית שכבתית: **שלד אמיתי** ← **שכבת גוף שקופה** ← **מודל מולבש** — עם שינוי גוף ופנים בזמן אמת דרך מצלמה ודרך פרומפט.

## הארכיטקטורה — שלוש שכבות

```
┌─────────────────────────────────────────────┐
│  שכבה 3: מודל מולבש (GLB/GLTF/VRM)          │  model-attach.js
│    retargeting לפי מפות שמות עצמות           │
├─────────────────────────────────────────────┤
│  שכבה 2: גוף שקוף נפחי                       │  body-layer.js
│    קפסולות פיזיקליות, מגיב לשריר/משקל        │
├─────────────────────────────────────────────┤
│  שכבה 1: השלד                                │  skeleton.js
│    26 עצמות, היררכיה תואמת VRM-humanoid      │
│    פרופורציות: קאנון 8 הראשים                │
└─────────────────────────────────────────────┘
          ▲                    ▲
   פרומפט → פרמטרים      מצלמה → נקודות ציון
   prompt-mapper.js      camera-tracker.js + retarget.js
```

## הרצה מקומית

הדמו משתמש ב-ES modules, אז צריך שרת סטטי (לא פתיחת קובץ ישירות):

```bash
cd human-avatar-engine
python3 -m http.server 8080
```

ואז לפתוח `http://localhost:8080/demo/` בדפדפן. כפתור "הפעלת מצלמה" טוען את MediaPipe ומתחיל מעקב גוף ופנים בזמן אמת.

## נוסחת שביל החלב

זרועות הגלקסיה מתוארות על ידי ספירלה לוגריתמית עם זווית פתיחה של ‎~12.5°‎:

```
r(θ) = r₀ · e^(θ·tan φ)
```

במנוע היא משמשת כמקור קצב אורגני:
- **נשימה** — שתי "זרועות" סינוס בפאזות שנגזרות מזווית הפתיחה (`breathingCurve`).
- **גלי תנועה בעמוד השדרה** — פאזות לפי אורך הקשת של הספירלה (`chainPhases`), כך שהגל מאיץ אקספוננציאלית במקום להתקדם לינארית.
- **דעיכת מורפים** — כמו פרופיל צפיפות הדיסקה הגלקטית `Σ(r) = Σ₀·e^(−r/h)‎` (`discFalloff`).

## חיבור מודל שפה (DeepSeek / Claude)

`prompt-mapper.js` כולל פירוש מקומי (עברית + אנגלית) בלי רשת, ו-`createLLMMapper` — מחבר גנרי לכל מודל שמחזיר JSON לפי `BODY_PARAMS_SCHEMA`. דוגמת חיבור ל-DeepSeek נמצאת בהערות הקובץ.
